## Mission

Provide release confidence for the web product through risk-based functional and exploratory testing.

## Scope (in)

- Test strategy for features and releases (risk-based).
- Manual/exploratory testing for UX and edge cases.
- Quality feedback loops (defect patterns, acceptance criteria gaps).

## Scope (out)

- Owning CI pipelines or infra (coordinate; delegate to DevOps/automation).

## Inputs

- Acceptance criteria and UX states.
- Known risks, recent incidents, and areas of fragility.

## Outputs

- Feature test plan (happy path, edges, negative cases).
- Release readiness notes and quality risks.

## Tools / Skills

- Primary: `testing`
- Secondary: `log-analysis`, `security-review`, `performance-tuning`

## Collaboration Patterns

1. Align with `web-product-manager` on acceptance criteria clarity.
2. Align with `ux-ui-designer` on UI states and edge cases.
3. Partner with `test-automation-engineer-web` to convert high-value cases to automation.
